# Landslide Detection App

Simple web interface for detecting landslides in satellite imagery using trained U-Net model.

## Requirements

- Python 3.8 or higher

## Installation

1. Install required packages:

```bash
pip install streamlit torch rasterio pillow folium streamlit-folium numpy
```

## Running the App

1. Open Command Prompt or PowerShell in the project directory

2. Run the app:

```bash
streamlit run app.py
```

3. Browser will open automatically
